# Day 2 · Python Q1 — Reverse Echo

**Difficulty:** ⭐ · **Target:** 4 min

Write a Python program `q01.py` that prints its command-line arguments to standard
output on one line, in **reverse order**, separated by single spaces.

```
./q01.py a b c
c b a
./q01.py hello
hello
./q01.py

./q01.py one two three four
four three two one
```

* With no arguments it should print an empty line.
* Your answer must be Python only. You may not run external programs.
* No error checking necessary.
